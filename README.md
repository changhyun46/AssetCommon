# AssetCommon

이미지, 동영상, 문서 및 대용량 데이터셋을 관리하기 위한 공통 저장소입니다.

## 저장 원칙

- `data/`: Git으로 추적하는 스키마, 메타데이터, 소형 샘플
- `assets/`: Git에서 제외하는 원본 미디어와 대용량 데이터
- `raw/`: 수집·입수한 원본 파일
- `processed/`: 정제·변환된 결과물
- 메타데이터의 파일 경로는 저장소 기준 상대 경로(`assets/...`)를 사용

대용량 파일을 팀과 공유하거나 버전 관리해야 하는 경우 Git LFS, DVC, S3 또는 MinIO를 사용하세요.

## 디렉터리

```text
data/       스키마, 메타데이터, AI 테스트용 샘플
assets/     실제 데이터·이미지·동영상·문서
src/        수집 및 데이터 처리 코드
scripts/    실행용 보조 스크립트
configs/    경로 및 파이프라인 설정
```
